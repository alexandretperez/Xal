# Xal

**A concise library of .NET extension members**

A lightweight and practical collection of extension members for .NET, designed to simplify everyday coding tasks. It provides intuitive helpers for working with strings, numbers, dates, collections, XML, encodings, and more.

---

## ✨ Features

- **String utilities**  
  Parse to nullable types, email/URL validation, diacritic removal, token replacement, truncation, title casing.

- **Date & time helpers**  
  Start/end of day, week, month, quarter, year; difference calculations; weekend detection.

- **Collections & dictionaries**  
  Chunking, splitting, index finding, conditional removal, safe value usage.

- **Numeric extensions**  
  Clamping, range checks, rounding, truncation, absolute values, sign detection.

- **XML helpers**  
  Namespace-agnostic element and attribute queries.

- **Encoding utilities**  
  Base64Url encode/decode.

- **Streams & builders**  
  Read all lines (sync/async), formatted `AppendLine`.

---

## 🚀 Why use it?

- Eliminates repetitive boilerplate code  
- Improves readability and maintainability  
- Works seamlessly with modern C# features, including **extension blocks in C# 14**
